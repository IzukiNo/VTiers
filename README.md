# VTiers
Bring **VNList tiers directly into Minecraft**.

VTiers is a client-side mod that displays player tier information from [VNList](https://vnlist.asia) while you play, allowing you to check competitive rankings without leaving the game.

## Why VTiers?
- View player tiers directly in-game
- Check tiers from the tab list and chat
- Look up player profiles and tier information
- Switch between supported gamemodes
- Customize tier icons, colors, positions and display options
- Configure everything through an in-game configuration screen

## Before You Download
- VTiers is a **client-side** mod and does not need to be installed on the server.
- Tier information is provided by **VNList** and may change as VNList data is updated.
- An internet connection is required to retrieve player tier information.
- VTiers is based on the original **[Tiers](https://modrinth.com/mod/tiers)** project and has been adapted to use VNList as its tier data source.
